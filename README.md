# 비장이 된 아내

「이춘풍전」을 바탕으로 한 수업용 서사 RPG

- 만든이: 경포고등학교 한예지
- 원작: 작자 미상 「이춘풍전」(조선 후기 판소리계 소설)
- 원문 대목: 경포고등학교 고전 읽기 수업 활동지(일부는 EBS 수능특강 수록 대목)
- 현대어 풀이·서술·게임 대사: 새로 씀
- 그림: OpenAI 이미지 생성(Codex CLI)으로 만든 AI 생성 이미지
- 배경음: 게임 안에서 웹 오디오로 합성한 창작 가락(외부 음원 없음)
- 글꼴: 송명, 고운바탕, IBM Plex Sans KR (SIL Open Font License)
- 제작 도구: Claude(Anthropic), Codex(OpenAI)
